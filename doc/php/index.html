h5p.classes.php

Main H5P API surface and core implementation.

5,630 lines

This is the central file of the library. It defines the platform integration interface, package validation, persistence orchestration, constants, core runtime helpers, content dependency resolution, AJAX helpers, H5P Hub integration, and content parameter validation.

Defined types

H5PFrameworkInterface, H5PValidator, H5PStorage, H5PPermission, H5PDisplayOptionBehaviour, H5PContentHubSyncStatus, H5PContentStatus, H5PHubEndpoints, H5PCore, and H5PContentValidator.

Integration role

Frameworks implement the interface in this file and pass that implementation to H5PCore, H5PValidator, and H5PStorage.

This file contains a large monolithic API. When changing it, check both platform implementations and JavaScript runtime expectations because many methods define cross-layer behavior.

embed.php

HTML template for iframe-based H5P embeds.

template

This file is not a class. It emits a complete HTML document for embedded H5P content. It expects variables from the caller and escapes language, title, script URLs, style URLs, and content ID before output.

Expected variables$lang, $content, $scripts, $styles, $additional_embed_head_tags, and $integration.
OutputA document with <html class="h5p-iframe">, asset tags, <div class="h5p-content" data-content-id="...">, and a JSON-encoded H5PIntegration JavaScript object.
Security behaviorUses htmlspecialchars(..., ENT_QUOTES, 'UTF-8') for scalar HTML attributes/text and intval() for content ID.
